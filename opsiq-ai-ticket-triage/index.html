OpsIQ AI Ticket Triage

🚀 ▶ Demo

OpsIQ AI Ticket Triage is a full-stack ticket management application designed to streamline IT support and operations workflows. The application enables users to create, manage, search, and track support tickets while leveraging an AI-powered engine to automatically analyze ticket content and generate categories, priorities, summaries, and suggested next steps.

Users can monitor ticket status, from Open to In Progress and Resolved. Dashboard metrics, filters, search and timestamps improve workflow visibility.

Built with Angular, Spring Boot, PostgreSQL and RESTful APIs.

TECH STACK

Angular · HTML/CSS · Spring Boot · REST API · TypeScript · PostgreSQL · OpenRouter · Java

WHAT I BUILT / WORKED ON

  • Designed and developed a full-stack ticket management application using Angular, Spring Boot, and PostgreSQL.
  • Implemented RESTful APIs for ticket creation, retrieval, status updates, and deletion.
  • Developed an AI-powered ticket analysis engine that generates categories, priorities, summaries, and recommended actions.
  • Built dashboard analytics with operational metrics, search, and status filtering.
  • Integrated PostgreSQL with Spring Data JPA for persistent storage.
  • Developed responsive frontend components using Angular and TypeScript.
