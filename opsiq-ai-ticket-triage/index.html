OpsIQ AI Ticket Triage

🚀▶️ Demo

OpsIQ AI Ticket Triage is a full-stack ticket management application designed to streamline IT support and operations workflows. The application enables users to create, manage, search, and track support tickets while leveraging an AI-powered rules engine to automatically analyze ticket content and generate categories, priorities, summaries, and suggested next steps.

In this web-based application, users can submit tickets, monitor ticket status, and manage the ticket lifecycle from Open to In Progress and Resolved. The system provides dashboard metrics, status filtering, search functionality, and automatic timestamp tracking to improve ticket visibility and workflow efficiency.

The application is built using Angular, Spring Boot, and PostgreSQL with a RESTful API architecture. The frontend communicates with backend services to perform ticket management operations while maintaining persistent ticket data storage.
