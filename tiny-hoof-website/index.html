🚀▶️ Live Website

An interactive, customer-driven website built from the ground up and actively used by the business for over 5 years. Developed on a framework with custom extensions as part of a 4-person team.

This website aims to showcase the organization's facilities, services, donor page, social media platforms, and contact information to current clients and guests. The Tiny Hoof website features clear images, detailed descriptions, and biographical information about the organization, its staff, and animals. It was developed using the Weebly website builder, customizable extensions, and additional HTML code. Various extensions were implemented to support functions for both users and administrators. The website is fully accessible on desktop, laptop, and mobile devices. Throughout the development process, the team maintained ongoing communication with the client to ensure that their requirements were met. The project was organized in one-week increments using an agile framework 'SCRUM'. This process fosters accountability and iterative progress.
