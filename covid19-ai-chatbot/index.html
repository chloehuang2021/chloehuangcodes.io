COVID-19 AI Chatbot

Real-time interactive chatbot with voice-to-text capabilities for COVID-19 related questions. The project used official government sources and could direct users to relevant agencies for further information.

Built for desktop and mobile, designed not to collect personally identifiable information.

Live Demo / Repository⟶

TECH STACK

HTML/CSS · JavaScript · Vue · Sass

WHAT I BUILT / WORKED ON

  • Trained conversational agents using Dialogflow intents, phrases, actions and responses.
  • Architected conversational flows integrating 4 agents, 50 intents, 400 phrases, 50 actions, and 200 responses.
  • Added timestamps with JavaScript and Node.js.
  • Optimized chatbot accuracy through conversational AI improvements.

INSIDE THE BUILD

  • Real-time COVID-19 updates
  • Government-verified information
  • Open-ended Q&A
  • Voice-to-text interaction
  • Desktop & mobile support
  • Privacy-first experience
