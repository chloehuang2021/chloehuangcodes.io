ChloeHuangCodes — redesigned About Me homepage

This ZIP has ONE replacement `index.html`. The original user-uploaded “Chloe Avatar 6(1).jpg” is embedded directly into the HTML as an unchanged JPEG data URI, so the avatar works without uploading a separate file. No image edits were applied.

Installation:
1. Open your existing repository root index.html in GitHub.
2. Edit it (pencil icon), select all, and replace its contents with this new index.html.
3. Commit changes. Do NOT replace the other page folders or rename your repository.
4. The homepage still refers to existing assets/cloud-banner.png, assets/sun-icon.png, assets/opsiq-preview.jpg, assets/tiny-hoof-preview.png, assets/covid-chatbot-preview.png, assets/paper-plane.png, and assets/cloud-temp.jpg. These were in prior website packages; leave them in the repo.
5. Check homepage and links after GitHub Pages publishes.

The biography is collapsed by default and uses native HTML <details>, so Read more/Read less works without JavaScript. The Projects dropdown uses a small script, supports click-outside and Escape.

External links use existing verified destinations: chloehuangjobs@gmail.com, linkedin.com/in/chloe-huang-tech/, github.com/chloehuang2021. Resume button links to the existing Resume & Contact page so it doesn't depend on Wix-hosted PDF.
